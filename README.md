# Devopsautomation
CI/CD &amp; DevSecOps Automation

Overview

This project automates the build of a Python application into Docker images, along with scanning the Terraform configuration files using terrascan and enforcing security policies through OPA (Open Policy Agent). Jenkins is used for Continuous Integration and Continuous Deployment (CI/CD), and the entire process is automated using Groovy scripts. Reports are generated from tools like Trivy, Syft, and Grype, and stored as JSON files for analysis and auditing.

Prerequisites

Before running the Jenkins pipeline and automation scripts, ensure that you have the following installed:

Jenkins (latest version with required plugins)

Groovy (for running the automation scripts)

Docker (to build and run Python Docker images)

Terraform (for managing infrastructure)

Terrascan (for scanning Terraform configurations)

OPA (Open Policy Agent for enforcing security policies)

Trivy (for security scanning of Docker images)

Syft (for generating Software Bill of Materials)

How It Works
1. Jenkins Pipeline

The project uses Jenkins to automatically build and deploy the Python application into Docker containers. The pipeline is defined in the Jenkinsfile located in the jenkins/ directory. The pipeline consists of several stages:

Checkout: Retrieves the latest code from the repository.

Build Docker Image: Builds the Python application into a Docker image.

Scan Docker Image: Uses Trivy to scan the Docker image for vulnerabilities and generates a report.

Scan Terraform: Uses terrascan to scan Terraform files and identifies security misconfigurations.

Policy Check: Enforces security policies via OPA (Open Policy Agent) on the Terraform configuration files.

2. Groovy Automation Scripts

The automation is driven by Groovy scripts which are used in Jenkins to:

Build the Python Docker image.

Run scans with Trivy and Syft to ensure that the Docker images are secure and provide a Software Bill of Materials (SBOM).

Run terrascan to scan the Terraform files.

Enforce policies using OPA and the rego policy file.

The following scripts are available:

build_image.groovy: Builds the Docker image using a Dockerfile that contains the instructions to build the Python application.

scan_terraform.groovy: Scans Terraform code for security issues using terrascan.

scan_docker.groovy: Uses Trivy and Syft to scan the Docker image and generate security reports.

3. Terraform & OPA Policies

In the policies/ directory, the opa-policy.rego file is used to define security policies for Terraform. These policies are checked whenever terrascan scans the Terraform configuration files.

4. Security Reports

The security reports are stored in the reports/ directory as JSON files. These reports can be analyzed later for vulnerabilities and compliance issues.

grype-report-25.json: Contains a security report from Trivy, listing vulnerabilities found in the Docker image.

syft-sbom-25.json: Provides a Software Bill of Materials (SBOM) generated by Syft.

trivy-report-25.json: Another security scan report generated by Trivy.

Setup and Installation
1. Clone the Repository
git clone <repository-url>
cd <repository-name>

2. Install Required Tools

Make sure to install the required tools on your local environment or Jenkins server. Here are the installation steps for each tool:

Jenkins: Follow the official Jenkins installation guide
.

Groovy: Install Groovy
.

Docker: Follow Docker installation instructions
.

Terraform: Install Terraform from HashiCorp's website
.

Terrascan: Install Terrascan by following the installation guide
.

Trivy: Install Trivy by following Trivy's installation guide
.

Syft: Install Syft from the official website
.

OPA: Install OPA by following OPA's installation guide
.

3. Set Up Jenkins

Create a Jenkins job and configure it to use the Jenkinsfile in this repository.

Make sure the Jenkins job has access to Docker, Terraform, and other required tools.

4. Configure Terraform

Ensure your Terraform configuration files (main.tf, variables.tf, etc.) are set up in the terraform/ directory. Terraform should be initialized and the state should be managed accordingly.

cd terraform
terraform init

5. Configure OPA Policies

Modify the opa-policy.rego file to adjust the policy as per your security requirements. This policy will be used during the terrascan phase to enforce security checks.

6. Running the Pipeline

Once everything is set up, run the Jenkins pipeline. Jenkins will execute the pipeline steps:

Build the Docker image.

Scan Docker image using Trivy and Syft.

Scan Terraform using Terrascan.

Enforce OPA policies during the Terraform scan.

7. Reviewing Reports

After the pipeline completes, check the reports/ directory for generated security reports.
